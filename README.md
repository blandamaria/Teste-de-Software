# 🌱 EcoCondo — Garantia de Qualidade e Testes de Software

Repositório dedicado ao planejamento, execução e documentação dos testes funcionais (manuais) e testes unitários automatizados desenvolvidos para o sistema **EcoCondo**.

---

## 📖 Sobre o Projeto EcoCondo

O **EcoCondo** é uma plataforma web voltada para a gestão sustentável e colaborativa de condomínios residenciais. O sistema conecta **síndicos** e **moradores**, incentivando práticas ecológicas por meio de monitoramento de consumo, gamificação e transparência administrativa.

### Principais Funcionalidades do Sistema
* **Gestão de Condomínios e Usuários:** Cadastro e autenticação de condomínios (via CNPJ), síndicos e moradores, com edição de perfis e controle de acesso.
* **Controle de Sustentabilidade:** Registro de status e desligamento de pontos de iluminação, além do acompanhamento de metas mensais de consumo.
* **Descarte Seletivo e Gamificação:** Lançamento de resíduos recicláveis (plástico, papel, vidro, metal) com conversão automática em pontos, consulta de saldo e ranking entre moradores.
* **Gestão Financeira de Consumo:** Registro e acompanhamento mensal de contas de água/energia do condomínio.
* **Comunicação e Relatórios:** Mural de avisos publicado pelo síndico para os moradores e relatórios consolidados dos indicadores de sustentabilidade.
